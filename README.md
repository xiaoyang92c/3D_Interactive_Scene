# 羽见千年 · 金沙遗址 3D 互动体验

一个以金沙遗址文化为主题的沉浸式 Web 3D 互动项目。玩家将跟随角色穿行于三段场景，在飞行探索中了解金沙遗址的自然环境、礼仪文明与文化记忆。

## 在线体验

[https://www.jinsha3d.fun/](https://www.jinsha3d.fun/)

## 项目特色

- 由 15 个场景节点组成的连续飞行旅程
- “自然之源”“文明之光”“记忆重生”三个叙事阶段
- 场景信息卡、剧情对白与空间音效
- 雾效、环境光、景深层次和节点粒子效果
- 支持带动画的文明之门模型
- PC 与移动端分别适配画质和性能策略
- 支持高画质、低画质切换
- 结尾界面提供重新启程与返回首页，并带有淡出过渡

## 三阶段内容

| 阶段 | 主题 | 主要内容 |
| --- | --- | --- |
| 第一阶段 | 自然之源 | 岩层秘境、千年古树、山水环境与礼器之门 |
| 第二阶段 | 文明之光 | 太阳神鸟、黄金面具、玉璧、青铜纹样与钟铃回廊 |
| 第三阶段 | 记忆重生 | 文物碎片、文明线索与文明之门 |

## 操作方式

### PC 端

| 按键 | 功能 |
| --- | --- |
| `A` / `D` 或左右方向键 | 左右移动 |
| `W` / `S` 或上下方向键 | 升降 |
| `Shift` | 加速飞行 |
| `Space` | 停止或继续 |
| `Esc` | 暂停菜单 |
| `F2` | 打开场景调整面板 |

### 移动端

- 在屏幕上拖动控制方向
- 使用界面按钮控制前进、加速和暂停
- 默认采用面向移动设备的低画质渲染策略

## 技术栈

- React 19
- TypeScript
- Three.js
- React Three Fiber
- GSAP
- Vinext / Vite
- GLB / glTF 3D 资源
- Draco 模型压缩

## 项目结构

```text
3D_Interactive_Scene/
├─ app/
│  ├─ JinshaExperience.tsx      # 互动场景与流程
│  ├─ sceneAssets.ts            # 模型、节点与文本配置
│  └─ globals.css               # 页面和 UI 样式
├─ public/
│  ├─ audio/                    # 音频资源
│  ├─ draco/                    # Draco 解码器
│  └─ models/

│     ├─ jinsha-optimized/      # PC 优化模型
│     ├─ jinsha-eco/            # 移动端轻量模型
│     └─ jinsha-colliders/      # 碰撞模型
├─ package.json
└─ README.md
```

## 开发环境

- Node.js 22.13.0 或更高版本
- npm

安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

运行测试：

```bash
npm test
```

## 场景配置

模型路径、节点文本、位置、旋转、缩放和阶段范围集中维护在 `app/sceneAssets.ts`。主要交互、相机轨迹、性能分级、粒子效果与剧情流程位于 `app/JinshaExperience.tsx`。

## 兼容性

推荐使用支持 WebGL 2 的现代浏览器。移动设备会根据设备性能与屏幕规格降低像素比、特效强度和模型复杂度，以缩短加载时间并提升运行稳定性。

## 项目介绍

《羽见千年》通过连续飞行、文物展示与阶段化叙事，将金沙遗址的自然环境、礼仪信仰和文明记忆串联为一段可探索的数字旅程，让观众在互动中感受古蜀文明的独特魅力。
